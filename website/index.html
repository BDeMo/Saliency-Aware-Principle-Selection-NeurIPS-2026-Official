01 / THE PROBLEM

More tokens do not necessarily mean more vision.

A vision-language model sees the image at the start, but regenerates text at every step. As the chain grows, an early visual mistake can be repeated until it reads like evidence.

Directly inserting tool output is not a clean fix: one incorrect detection can become a premise for everything that follows. The real question is how an agent can use tools while remaining able to disagree with them.

02 / THE SHIFT

Search over how to reason, not just what token comes next.

SAP evolves short principles. Each principle produces independent routes from the original image and prompt. A frozen grounding tool checks object support; agreement, diversity, and uncertainty help decide which behaviors survive.
